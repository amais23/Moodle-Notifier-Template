# 📋 Moodle Notifier — v2 需求規格文件 (LINE 按鈕化 + Discord 機器人)

> **專案願景**：以「使用者體驗與便利性」為核心，將 LINE 機器人升級為**免輸入、一鍵按鈕化**的智慧隨身助理，並引進 **Discord 機器人服務**，支援斜線指令與精美 Embed 訊息。

---

## 🎯 願景場景 (User Scenario)

```
早上起床 → 打開 LINE 對話框，直接點擊下方常駐選單的「📋 待繳作業」
          → LINE 立即彈出精美的 Flex 卡片，顯示 3 個待繳作業。
          → 點擊卡片上的「查詢詳情」按鈕，立刻得知該作業是否已評分與繳交狀態。

課間討論 → 開啟我的 Discord 伺服器
          → 在頻道中輸入「/upcoming」斜線指令，機器人回傳一週內行程。
          → 收到 Discord 機器人發布的「[成績公告]：近代物理 HW2 已公布」，附帶精美漸層色標。
```

---

## 📦 功能模組與規格

### 模組 1：LINE 機器人按鈕化 (LINE Button-Driven UX)
**目的**：免手動打字輸入指令，全按鈕點擊式操作，大幅提升手機端便利性。

#### 1.1 常駐圖文選單 (Rich Menu)
* **規格**：在 LINE 對話框下方常駐一個 `6 格` 或 `4 格` 的精美圖文選單。
* **按鈕規劃**：
  1. **📚 我的課程**：點擊發送 `/courses`
  2. **📋 未繳作業**：點擊發送 `/assignments`
  3. **📊 成績明細**：點擊發送 `/grades`
  4. **📅 近期行程**：點擊發送 `/upcoming`
  5. **💬 私訊通知**：點擊發送 `/messages`
  6. **🌐 控制網頁**：直接點擊外連，開啟 Web Dashboard。
* **部署方式**：
  - 提供一個簡單的 Python 腳本，透過 LINE API 一鍵上傳與設定 Rich Menu，或是引導使用者直接在 LINE 官方帳號後台 (LINE Official Account Manager) 的視覺化介面中上傳底圖並綁定指令，以便非技術人員使用。

#### 1.2 卡片式互動訊息 (Flex Messages)
* **規格**：取代原先單調的純文字訊息，改用 LINE 特有的 Flex Message 進行氣泡卡片排版。
* **卡片內容設計**：
  - **作業卡片 (Assignment Card)**：每個作業以獨立的區塊呈現，帶有截止倒數彩色狀態標記（如紅色代表僅剩 24h）。卡片下方附帶 `[ 🔍 查詢繳交狀態 ]` 按鈕，點擊後會即時回覆該作業的繳交情形與教授評分，無需手動查詢。
  - **課程教材卡片 (Course Content Card)**：點擊單一課程後，以卡片清單列出最新講義檔案，下方附帶 `[ 📥 下載講義 ]` 按鈕，直接觸發安全代理下載。
  - **幫助卡片 (Help Card)**：以按鈕清單（Button Template）呈現，使用者點選按鈕直接觸發相應功能。

---

### 模組 2：Discord 機器人服務 (Discord Bot Integration)
**目的**：支援 Discord 平台，提供更豐富的卡片排版與斜線指令 (Slash Commands)，適配習慣在 Discord 進行小組討論的學生。

#### 2.1 斜線指令系統 (Slash Commands)
* **規格**：在 Discord 頻道中輸入 `/` 即可喚醒指令，支援自動補齊與引導。
* **指令清單**：
  - `/courses` — 查看本學期修習的課程列表。
  - `/todo` — 查詢目前所有未繳交的作業清單與截止倒數。
  - `/grades` — 查看所有科目的成績。
  - `/upcoming` — 查詢一週內即將到期的行事曆事項。
  - `/messages` — 讀取最新 Moodle 私訊。
  - `/help` — 顯示指令與操作手冊。

#### 2.2 富文本嵌入訊息 (Rich Embeds)
* **規格**：Discord 機器人發送的通知均採用 `Discord Embed` 格式。
* **設計要點**：
  - 依據通知的優先級別顯示不同的左側邊框顏色（例如：公告與緊急通知顯示紅色 `0xEF4444`；作業到期提醒顯示橙色 `0xF59E0B`；成績公布顯示綠色 `0x10B981`）。
  - Embed 卡片中清楚標示：課程名稱、發布教師、截止日期、內容摘要。
  - 卡片底部附帶 `[ 🌐 開啟 Web Dashboard ]` 按鈕，點擊可直接外連。

## 🏗️ 系統架構擴充與「獨立運作」設計 (v2)

為了實現使用者配置的最高彈性，**LINE 機器人與 Discord 機器人必須能夠完全「獨立運作」且高度解耦**。

```
                       +-----------------------------+
                       |       NTNU Moodle API       |
                       +--------------+--------------+
                                      ^
                                      | (Stateless API)
                                      v
   +------------+      +--------------+--------------+      +------------+
   |  LINE App  |<---->|       FastAPI 後端          |<---->|  Discord   |
   | (可選啟用) |      | • Web Dashboard (API 核心)  |      | (可選啟用) |
   +------------+      | • LINE Webhook 路由          |      +------------+
                       | • Discord Gateway 監聽       |
                       +-----------------------------+
```

* **獨立運作技術規格**：
  1. **憑證解耦**：
     - LINE 機器人僅依賴 `LINE_TOKEN` 與 `LINE_CHANNEL_SECRET`。
     - Discord 機器人僅依賴 `DISCORD_BOT_TOKEN`。
     - 網頁儀表板 (Web Dashboard) 僅依賴使用者登入時輸入的 Moodle 帳密。
  2. **動態載入機制**：
     - 若使用者**未設定** LINE 憑證，FastAPI 仍能正常啟動，僅在存取 `/webhook/line` 時拒絕請求或不加載 LINE 模組，不影響網頁端與 Discord。
     - 若使用者**未設定** Discord 憑證，系統將**完全跳過** Discord Bot 的 WebSocket 初始化與 Gateway 連線，主服務（FastAPI/Web Dashboard/LINE）照常運作。
     - **即使兩者皆未啟用**，Web Dashboard 依然能做為獨立網頁版控制台正常登入與工作。
  3. **定時推播解耦 (GitHub Actions)**：
     - 定時排程推播程式碼會動態偵測 Secrets，只對已配置憑證的平台（LINE 和/或 Discord）發送通知。

## 🛠️ 開發與配置便利性要求
1. **雙平台獨立配置**：
   - 繼續保持「一鍵部署」的特性，所有機器人憑證皆為可選（Optional）環境變數。
2. **LINE Rich Menu 底圖模板**：
   - 在專案中提供選單底圖 PNG 模板與配置說明，讓每位使用者都能在 LINE 後台 3 分鐘內完成按鈕配置。
